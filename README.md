# KEEL — Classical Sculpture & Concentric Light Rings 3D

Interactive real-time WebGL / Three.js architectural experience combining classical Greco-Roman colonnade sculpture, liquid-silver Carrara marble PBR materials, volumetric cumulus sky shaders, and concentric halo light rings.

## Stack
- React 19 + TypeScript + Vite
- Three.js WebGL with custom procedural PMREM environment mapping, fluted Corinthian columns, sculpted classical drapery, and volumetric sky shader
- GSAP camera choreography & interactive harmonic ring controls
- Tailwind CSS v4 design tokens
